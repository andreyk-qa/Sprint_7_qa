Проект организован следующим образом:

| Файл/Папка | Назначение |
| :--- | :--- |

| `test_order_creation.py` | Тесты на создание заказа. |
| `test_order_list.py` | Тест на получение списка заказов. |

## Описание тестов

Тесты используют декораторы `allure` для формирования структурированных отчетов.

### Тесты Курьеров

Проверяют ручки `/api/v1/courier` (создание) и `/api/v1/courier/login` (авторизация).

| Файл | Тест | Описание | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| `test_courier_creation.py` | `test_successful_creation_courier` | Создание курьера с корректными данными. | Код 201, `{'ok': True}`. |
| `test_courier_creation.py` | `test_repeated_creation_courier` | Попытка повторного создания курьера с теми же данными. | Код 409, сообщение 'Этот логин уже используется...'. |
| `test_courier_creation.py` | `test_creation_courier_without_required_fields` | Создание курьера без обязательных полей (`login` или `password`). | Код 400, сообщение 'Недостаточно данных для создания...'. |
| `test_courier_creation.py` | `test_creation_courier_with_used_login` | Создание курьера с логином, который уже используется. | Код 409, сообщение 'Этот логин уже используется...'. |
| `test_login_courier.py` | `test_successful_authorization_courier` | Успешная авторизация курьера. | Код 200, тело содержит 'id' типа `int`. |
| `test_login_courier.py` | `test_authorization_courier_without_required_fields` | **(Пропущен)** Авторизация без обязательных полей (`login` или `password`). | Ожидается 400, сообщение 'Недостаточно данных для входа'. **Примечание:** Тест пропущен (`@pytest.mark.skip`) из-за найденного бага при пустом пароле. |
| `test_login_courier.py` | `test_authorization_courier_with_wrong_required_fields` | Авторизация с неверным логином или паролем. | Код 404, сообщение 'Учетная запись не найдена'. |

### Тесты Заказов

Проверяют ручку `/api/v1/orders` (создание и получение списка).

| Файл | Тест | Описание | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| `test_order_creation.py` | `test_order_creation_with_color_options` | Создание заказа с различными опциями цвета: 'BLACK', 'GREY', оба, или без цвета. | Код 201, тело содержит `track` (трек-номер) типа `int`. |
| `test_order_list.py` | `test_get_order_list_success` | Получение общего списка заказов. | Код 200, тело содержит ключ `orders` со списком. |
